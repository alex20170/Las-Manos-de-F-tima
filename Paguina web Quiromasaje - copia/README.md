# Fátima Zen Touch - Página Web de Quiromasaje y Reiki

Web profesional para reservas de quiromasaje y sesiones de Reiki en Jerez de la Frontera.

## 🚀 Configuración Rápida

### 1. Configurar EmailJS (10 minutos)

1. Crea cuenta gratuita en: https://www.emailjs.com
2. Conecta tu Gmail: fatimalabradorgarcia@gmail.com
3. Crea una plantilla con estos campos:
   - {{cliente_nombre}}
   - {{servicio_elegido}}
   - {{fecha_cita}}
   - {{hora_cita}}
   - {{cliente_telefono}}
   - {{cliente_email}}
   - {{comentarios}}
4. Copia tus credenciales en `js/main.js` (líneas 5-7)

### 2. Personalizar

- Añade tu foto en `images/foto-perfil.jpg`
- Ajusta precios en `index.html` si es necesario
- Cambia horarios en `index.html` (línea 228)

### 3. Publicar

#### Opción A: Netlify (Gratis)
1. Arrastra la carpeta completa a netlify.com
2. ¡Listo!

#### Opción B: Hosting tradicional
1. Sube todos los archivos por FTP
2. Accede a tu dominio
