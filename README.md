# 🌿 Las Manos de Fátima - Quiromasaje y Reiki

Este es el repositorio oficial de la página web de "Las Manos de Fátima".

## 🚀 Cómo ejecutar el proyecto con Docker

Para que cualquier persona pueda ver la web exactamente igual que tú, hemos incluido una configuración de **Docker**.

### Requisitos previos
- Tener instalado [Docker Desktop](https://www.docker.com/products/docker-desktop/).

### Pasos para arrancar:

1.  **Clona el repositorio** o descarga la carpeta del proyecto.
2.  Abre una terminal en la carpeta raíz del proyecto.
3.  Ejecuta el siguiente comando:
    ```bash
    docker-compose up -d
    ```
4.  Abre tu navegador y entra en: [http://localhost:8080](http://localhost:8080)

## 📁 Estructura del proyecto
- `index.html`: Página principal.
- `servicios.html`: Carta de masajes y tratamientos.
- `reservar.html`: Sistema de reservas por WhatsApp.
- `css/`: Estilos premium y modo oscuro.
- `js/main.js`: Lógica de reseñas, modo noche y animaciones.
